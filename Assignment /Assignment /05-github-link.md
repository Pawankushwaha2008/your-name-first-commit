Assignment 5 – GitHub repository link

## 2. Push Steps
**Step 1:** Open GitHub and log in to your account.

**Step 2:** Click on **New Repository** and enter the repository name `MyProject`.

**Step 3:** Click **Create Repository**. Create an empty repository without adding a README file.

**Step 4:** Open your project folder in VS Code and open the terminal.

**Step 5:** Run the following commands:

```bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/MyProject.git
git push -u origin main
```

**Note:** Replace `YOUR-USERNAME` with your actual GitHub username.

**Step 6:** Open your GitHub repository and verify that your project files and commit history are visible.

**Step 7:** Copy your GitHub repository URL and paste it into the assignment.

## 8. Result

Successfully pushed the project to GitHub and verified the repository files and commit history.
